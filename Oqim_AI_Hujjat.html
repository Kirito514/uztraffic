def get_state(self):

        self.ns_queue / 40.0,              # NS navbatini 0-1 ga normalizatsiya

Nega 40 ga bo'lyapmiz? Neyron tarmoqlar 0-1 oralig'idagi raqamlar bilan eng yaxshi ishlaydi. 40 ta mashina bo'lsa 1.0 ga teng bo'ladi.

    # Mukofot: kamroq mashina kutsa yaxshi

Bo'lim 3: Neyron Tarmoq (Deep Q-Network)

Loyihaning miyasi — inson miyasiga o'xshash sun'iy neyron tarmoq.

class DQN(nn.Module):
    def __init__(self):
        self.network = nn.Sequential(
            nn.Linear(3, 128),     # 1-qatlam: 3 kirish → 128 neyron
            nn.ReLU(),              # Aktivatsiya: Manfiy sonlarni 0 qiladi
            nn.Linear(128, 128),    # 2-qatlam: 128 → 128 neyron
            nn.ReLU(),
            nn.Linear(128, 64),     # 3-qatlam: 128 → 64 neyron
            nn.ReLU(),
            nn.Linear(64, 4)        # Chiqish: 64 → 4 ta harakat
        )
Kirish (3 ta son): NS navbat, EW navbat, vaqt tsikli → Chiqish (4 ta son): Har bir harakatning Q-qiymati. AI eng yuqori qiymatli harakatni tanlaydi.
