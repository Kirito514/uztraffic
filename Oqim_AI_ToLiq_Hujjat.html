Chorraha Modeli

4 tomonlama chorraha: Shimol-Janub (NS) yo'nalishi va Sharq-G'arb (EW) yo'nalishi. Har tsiklda Puasson taqsimoti bo'yicha mashinalar keladi.

class Intersection:
    def __init__(self):
        self.ns_queue  = 0    # Shimol-Janub navbatidagi mashinalar
        self.ew_queue  = 0    # Sharq-G'arb navbatidagi mashinalar
        self.step_count = 0   # Hozirgi tsikl raqami
        self.max_steps  = 60  # Har epizod 60 tsikldan iborat

    def get_state(self):
        return np.array([
            self.ns_queue / 40.0,           # 0-1 ga normalizatsiya
            self.ew_queue / 40.0,
            (self.step_count % 10) / 10.0  # Vaqt tsikli
        ])

Puasson Taqsimoti — Mashinalar Kelishi

Har tsiklda qancha mashina kelishi np.random.poisson(8) orqali aniqlanadi. Bu real hayotdagi "tasodifiy kelish" ni modellashtiradi — o'rtacha 8 ta, lekin ba'zan 3, ba'zan 15 ta. Bu real transport statistikasiga eng yaqin matematik model.

def step(self, action):
    ns_incoming = np.random.poisson(8)  # O'rtacha 8 mashina NS dan keladi
    ew_incoming = np.random.poisson(6)  # O'rtacha 6 mashina EW dan keladi
    self.ns_queue += ns_incoming
    self.ew_queue += ew_incoming

    # 4 ta harakat (action): har biri qaysi yo'nalishga yashil beradi
    if   action == 0: ns_pass, ew_pass = 8,  0   # NS qisqa yashil
    elif action == 1: ns_pass, ew_pass = 0,  8   # EW qisqa yashil
    elif action == 2: ns_pass, ew_pass = 15, 0   # NS uzun yashil
    else:             ns_pass, ew_pass = 0,  15  # EW uzun yashil

    # Mukofot formulasi
    total_queue = self.ns_queue + self.ew_queue
    reward = 10.0 - total_queue * 0.5  # Kam mashina = yuqori mukofot

class DQN(nn.Module):
    def __init__(self):
        self.network = nn.Sequential(
            nn.Linear(3,   128),  # 3 kirish → 128 neyron
            nn.ReLU(),              # Manfiy sonlarni 0 qiladi
            nn.Linear(128, 128),  # 128 → 128
            nn.ReLU(),
            nn.Linear(128, 64),   # 128 → 64
            nn.ReLU(),
            nn.Linear(64,  4)    # 64 → 4 ta harakat
        )

Q(s, a) = r + γ × max Q(s', a')

Probka zonalarini avtomatik aniqlash

Nima uchun DBSCAN?

Tirbandlik zonalari tartibsiz shaklda bo'ladi. K-Means krug shaklida klaster qidiradi, DBSCAN esa har qanday shaklda zich joylashgan mashinalarni topadi. Shuningdek klaster soni oldindan ma'lum bo'lishi shart emas.

dbscan = DBSCAN(eps=6, min_samples=8)
labels = dbscan.fit_predict(mashina_koordinatalari)
# labels == -1 => Erkin ketayotgan mashina (shovqin)
# labels == 0,1,2... => Probka zonasi raqami

min_samples 8 Kamida 8 ta mashina bo'lsagina "probka" deb qabul qilinadi
